## Freedoom

Freedoom (https://freedoom.github.io) is a free content game for Doom engines, licensed under the modified BSD
license reproduced in `COPYING.txt`. It can be freely redistributed, with or without modification, as long as that
license text accompanies it.

## doom1.wad (shareware)

`doom1.wad` is the shareware version 1.9 of DOOM by id Software. It may be redistributed **only unmodified** and
under the shareware terms: it may be copied and distributed freely, as long as the file is not altered and no
payment is charged for the file itself. Do not edit this file. All rights to the game content remain with id Software.

## Commercial IWADs

`doom.wad`, `doom2.wad`, `plutonia.wad` and `tnt.wad` are commercial and are **never** committed or downloaded by
the build. You can drop your own copy into this directory (they are git-ignored) or point the game at them with
`-iwad <file>` or the `DOOMWADDIR` / `DOOMWADPATH` environment variables.
